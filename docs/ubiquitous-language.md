# Ubiquitous Language

## 核心节点类型

| Term | Definition | Aliases to avoid |
|------|------------|------------------|
| **Node（节点）** | 文件系统的基本抽象，统一定义文件、目录、链接的公共行为 | - |
| **File（文件）** | 拥有名称和内容大小的节点，其大小即为其内容大小 | 文件节点、file node |
| **Directory（目录）** | 拥有名称并可包含多个子节点的容器，其大小为所有子节点大小的总和 | 目录节点、文件夹、folder |
| **Link（链接）** | 指向既存节点的引用，迭代二引入，结构可能不再是严格树 | 符号链接、symlink |
| **Root（根目录）** | 唯一的顶层目录，路径为 `/`，无父节点 | 根节点 |

## 路径相关

| Term | Definition | Aliases to avoid |
|------|------------|------------------|
| **Absolute Path（绝对路径）** | 以 `/` 开头的完整路径，如 `/usr/local` | 完整路径 |
| **Path Segment（路径段）** | 路径中被 `/` 分隔的各部分，如 `usr`、`local` | 路径组件、目录名 |
| **Path Normalization（路径规范化）** | 去除冗余斜杠、解析 `.` 和 `..` 的过程，迭代二特性 | 路径解析（部分重叠） |
| **Path Resolution（路径解析）** | 将绝对路径转换为对应 Node 的过程 | 路径查找 |

## 命令

| Term | Definition | Aliases to avoid |
|------|------------|------------------|
| **MKDIR** | 创建目录的命令，若父目录不存在则忽略 | - |
| **TOUCH** | 创建文件或覆盖已有文件的命令 | - |
| **LS** | 列出目录下直接子节点（按字典序）的命令 | LIST |
| **INFO** | 输出节点大小的命令，目录大小递归计算 | - |
| **FIND** | 迭代二新增，递归搜索目录下同名节点 | - |
| **RM** | 迭代二新增，删除文件或空目录 | - |
| **LINK** | 迭代二新增，创建指向既存节点的链接 | - |

## 文件系统操作

| Term | Definition | Aliases to avoid |
|------|------------|------------------|
| **Size（大小）** | 文件的内容大小，或目录内所有节点大小的递归总和 | 尺寸、字节数 |
| **Size Calculation（大小计算）** | 递归遍历子节点并累加的过程 | 大小统计 |
| **SizeContext（尺寸上下文）** | 携带大小计算所需状态的上下文对象，迭代一为空实现，迭代二用于防环 | - |
| **Cycle Detection（环检测）** | 迭代二特性，防止链接导致的无限递归 | 环路检测 |

## 树结构

| Term | Definition | Aliases to avoid |
|------|------------|------------------|
| **Child（子节点）** | 直接隶属于某目录的节点 | 子目录（仅指目录） |
| **Parent（父节点）** | 包含某节点的直接上层目录 | 父目录 |
| **Descendant（后代节点）** | 某目录下递归所有层级的节点 | 子节点（语义过窄） |
| **Ancestor（祖先节点）** | 从根到某节点路径上的所有上级目录 | 上级节点 |

## 关系

- **Root** 是唯一没有父节点的 **Directory**
- **Directory** 包含零个或多个 **Child**（可以是 File 或 Directory）
- **File** 是叶子节点，不包含子节点
- **Link** 在迭代二中可指向任意 **Node**，使结构变为有向图而非严格树

## 歧义标记

- **"大小"** 用于指代 File 的内容字节数时明确，但用于 Directory 时需强调是**递归总和**，以区别于直接的子节点数量
- **"子节点"** 应明确为 **Directory 的直接子节点**，而非递归的所有后代
- **"路径解析"** 与 **PathUtil.normalize()** 有重叠：normalize 仅处理路径字符串，resolve 才返回 Node

## 示例对话

> **Dev:** "当执行 `MKDIR /usr/local` 时，如果 `/usr` 不存在怎么办？"
>
> **Domain Expert:** "直接忽略，不输出任何内容。"
>
> **Dev:** "那 `INFO /usr` 的时候，输出的是 `/usr` 下所有节点的递归总和？"
>
> **Domain Expert:** "对，目录大小需要递归计算每个子节点的大小并累加。"
>
> **Dev:** "如果迭代二加了 Link，`INFO /dir` 会重复计算同一个节点吗？"
>
> **Domain Expert:** "不能重复计数，而且要防止 Link 形成环导致无限递归。这就是为什么需要 SizeContext。"
>
> **Dev:** "所以迭代一的 SizeContext 是空的，迭代二才加防环逻辑？"
>
> **Domain Expert:** "正确。迭代一只有 File 和 Directory，不存在环。"
